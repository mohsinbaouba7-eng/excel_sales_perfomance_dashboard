# Superstore Sales & Statistical Performance Dashboard

An interactive Excel portfolio project analyzing regional sales, profit trends, and delivery/quantity metrics using advanced formulas, Pivot Tables, and dynamic dashboards.

## 📊 Project Overview
This project visualizes the classic "Superstore" dataset to uncover sales performance drivers, regional patterns, and operational distribution. It features a complete workbook layout encompassing raw data management, pivoting, statistical modeling, and an executive-level visual dashboard.

## 🛠️ Tools & Techniques Used
* **Microsoft Excel:** Advanced formulas, data modeling, and Conditional Formatting.
* **Statistical Analysis:** Average, Median, Mode, Standard Deviation, and Quartiles (`QUARTILE.INC`).
* **Data Visualization:** Custom interactive dashboards, Pivot Charts, and monthly trend graphs (Localized in French/English workflows).

## 📈 Key Insights & Findings
* **Central Tendency & Volume:** Transactions average **3.96 items** with a stable median and mode of **4 items**.
* **Interquartile Range:** The middle 50% of orders range between **3 and 5 items** ($Q1 = 3, Q3 = 5$), highlighting consistent mid-tier purchasing behavior.
* **Outliers:** Peak transactions reach up to **7 items** (driven by top consumer accounts like Sean O'Donnell).
* **Seasonality & Profitability:** Category-level breakdowns identify high-yield product segments (Technology vs. Furniture vs. Office Supplies) to guide regional stocking decisions.

## 📂 Workbook Structure
* `Dashboard`: High-level executive overview featuring KPI charts, regional bars, and category insights.
* `stats Summary`: Statistical breakdown evaluating delivery/quantity metrics, standard deviation, and quartiles.
* `pivots`: Aggregated pivot tables powering the visual dashboard components.
* `Sample - Superstore`: Cleaned underlying transaction dataset.

## 🚀 How to View
1. Download the `Sample - Superstore.xlsx` file from this repository.
2. Open it in Microsoft Excel (ensure macros and content are enabled if prompted).
